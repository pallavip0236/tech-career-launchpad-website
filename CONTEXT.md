*   **Build Tool:** Vite for an extremely fast development server and optimized production builds.

*   **Routing:** React Router DOM for client-side navigation.

*   **Form Handling:** React Hook Form with Zod for robust form validation and management.
*   **Other Libraries:** Includes `lucide-react` for icons, `next-themes` for theme management, `embla-carousel-react` for carousels, `recharts` for data visualization, `sonner` for toasts, and `vaul` for mobile-friendly drawers, among others, to enhance UI and interaction.

### Key Directories and Their Purpose
*   `public/`: Contains static assets like `favicon.ico`, `robots.txt`, and placeholder images.
*   `src/`: Houses all application source code.
    *   `src/App.tsx`: The main application wrapper component, often defining global layout or routing structure.
    *   `src/main.tsx`: The entry point for the React application, rendering `App.tsx`.
    *   `src/index.css`, `src/App.css`: Global and application-specific CSS styles.
    *   `src/components/`: Reusable, domain-specific UI components (e.g., `Hero`, `Navigation`, `Footer`).
    *   `src/components/ui/`: Core UI components generated or provided by shadcn/ui, built upon Radix UI primitives.
    *   `src/hooks/`: Custom React hooks for encapsulating reusable logic (e.g., `use-mobile`, `use-toast`).
    *   `src/lib/`: Utility functions and helper modules (e.g., `utils.ts` for common helpers).
    *   `src/pages/`: Top-level components representing distinct pages or routes in the application (e.g., `Index.tsx`, `NotFound.tsx`).
*   `tailwind.config.ts`: Tailwind CSS configuration file.
*   `vite.config.ts`: Vite build tool configuration file.
*   `components.json`: Configuration file for shadcn/ui components.
